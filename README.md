## Projects

### Draya · AI-powered learning management system
[![Live Demo](https://img.shields.io/badge/Live_Demo-2EA043?style=flat-square&logo=vercel&logoColor=white)](https://draya-lms.vercel.app/)
[![Source Code](https://img.shields.io/badge/Source_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/DrayaTeam/Draya-API)
